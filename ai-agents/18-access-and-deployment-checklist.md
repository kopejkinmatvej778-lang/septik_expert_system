# Доступы и деплой без Postgres

## Главный принцип

Система работает без отдельной SQL-базы. Источник данных:

- Google Drive - документы, папки клиентов, `_client-index.json`, записи звонков, КП, договоры;
- Google Sheets - монтажи, реестр документов, табель/выплаты, agent events;
- amoCRM - сделки, контакты, задачи, заметки, статусы продаж;
- телефония - звонки, записи, внутренние номера;
- VPS - backend API, очереди, workers, renderer, Telegram bot, веб-кабинет.

Пароли, токены и API-ключи не хранить в репозитории, промтах, документах или Google Drive. На VPS они лежат только в `.env`/secret storage.

## Что нужно подготовить от руководителя

### GitHub

- доступ к репозиторию или право создать новый репозиторий;
- право push/deploy key или GitHub token с минимальными правами;
- ветка для первого деплоя: `main` или отдельная `develop`.

### VPS

- IP сервера;
- SSH-пользователь;
- SSH-ключ или временный пароль для первичной настройки;
- домен/поддомен для кабинета, если нужен;
- доступ к DNS, чтобы поставить `A`-запись на VPS;
- право установить Docker, nginx, SSL, Redis, Python/Node runtime.

### Google

- Google аккаунт владельца или Google Workspace;
- корневая папка Drive для системы: `Септик Эксперт CRM`;
- Google Таблица `Монтажи`;
- Google Таблица `Реестр документов`;
- Google Таблица `Табель/Выплаты`, если запускаем учет людей;
- Google Cloud project;
- OAuth client или service account для Drive API и Sheets API;
- доступ service account к нужным папкам и таблицам.

### amoCRM

- домен аккаунта amoCRM;
- OAuth integration/client id/client secret/redirect uri;
- access token/refresh token после авторизации;
- список воронок и статусов;
- список обязательных полей сделки/контакта;
- ID пользователей менеджеров;
- webhook URL, который будет принимать VPS.

### IP-телефония

- провайдер телефонии;
- API endpoint;
- API key/token;
- webhook события завершения звонка;
- способ скачать запись звонка;
- список внутренних номеров менеджеров;
- правило хранения записей;
- подтверждение, что запись звонков юридически разрешена и клиенты/сотрудники уведомлены.

### Telegram

- Bot token от BotFather;
- список Telegram user_id руководителя, менеджеров, замерщиков;
- правила ролей: кто может создавать КП, нажимать "Ок", запускать договор, видеть паспортные данные.

### AI и транскрипция

- OpenAI API key или другой провайдер speech-to-text;
- выбранная модель транскрипции;
- выбранная модель анализа текста/агентов;
- месячный лимит расходов;
- правила хранения аудио и транскриптов.

## Что будет на VPS

- `backend API` - принимает webhook и команды интерфейса;
- `workers` - выполняют транскрипцию, анализ звонков, КП, договоры, cleanup;
- `Redis` - очередь задач и временные idempotency locks;
- `renderer` - Python + Pillow для КП, python-docx/LibreOffice/ReportLab для договоров;
- `frontend` - веб-кабинет руководителя;
- `nginx + SSL` - публичный HTTPS;
- `.env` - секреты API, не попадает в GitHub.

## Что не нужно покупать

- Postgres;
- отдельную managed database;
- n8n;
- Airtable/Notion как базу;
- S3 на MVP, если Google Drive полностью устраивает.

## Минимальная проверка готовности

Перед стартом сборки должны быть:

- VPS с SSH-доступом;
- GitHub repo;
- Telegram bot token;
- Google Drive папка и Sheets;
- Google API credentials;
- amoCRM OAuth доступ;
- API телефонии и тестовая запись звонка;
- OpenAI API key;
- домен или временный HTTPS URL для webhook.
