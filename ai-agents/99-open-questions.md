# Открытые вопросы перед боевым запуском

Эти вопросы нужны, чтобы агенты работали точно и не принимали лишние решения сами.

## CRM и статусы

1. Какие точные этапы amoCRM означают:
   - назначен замер;
   - замер выполнен;
   - КП отправлено;
   - договор выставлен;
   - договор заключен;
   - отказ?
2. Какие поля amoCRM являются обязательными для КП и договора?
3. Кто имеет право подтверждать КП-картинку: только руководитель или менеджеры тоже?
4. Кто имеет право запускать договор?

## КП

1. Где будет главный прайс: Google Таблица, файл в репозитории или админка?
2. Какие правила скидок разрешены и кто их подтверждает?
3. Нужно ли хранить финальное КП, на основе которого сделан договор, дольше 7 дней, или удалять все КП строго через неделю?
4. В каком формате финальное КП: только PNG-фото или еще PDF?
5. Кому отправлять КП-картинку в Telegram: замерщику, менеджеру, руководителю или всем?

## Договоры

1. Какие шаблоны договоров будут базовыми:
   - оборудование с монтажом;
   - погреб с монтажом;
   - кессон;
   - материалы/допработы?
2. Как генерируется номер договора?
3. Какие паспортные поля обязательны?
4. Нужно ли создавать договор сразу в DOCX и PDF?
5. Когда договор считается "заключен": по статусу amoCRM, по оплате, по вручную нажатой кнопке?

## Монтажи

1. Какая финальная структура Google Таблицы монтажей?
2. Кто назначает дату монтажа?
3. Кто назначает бригаду?
4. Что делать, если в Google Таблице вручную поменяли дату, а новое событие из договора/CRM содержит другую дату?

## Телефония

1. Какой провайдер будет в итоге: Билайн, Mango, UIS, Zadarma?
2. Есть ли API для скачивания записи сразу после звонка?
3. Какие внутренние номера у менеджеров?
4. Сколько дней хранить записи звонков?

## Доступы и права

1. Какие роли будут в веб-кабинете?
2. Нужна ли двухфакторная авторизация для руководителя?
3. Кто видит паспортные данные?
4. Кто видит записи звонков?
