# AI agents for Septik Expert

Эта папка описывает команду AI-агентов для внутренней системы ООО "Септик Эксперт": amoCRM, телефония, Telegram, генерация КП, договоры, Google Таблица монтажей, документы и кабинет руководителя.

## Как читать

1. `00-business-context.md` - общий контекст бизнеса и границы системы.
2. `01-team-rules-and-data-contracts.md` - правила командной работы, форматы данных и запреты.
3. Файлы `02-*` и далее - инструкции конкретных агентов.
4. `99-open-questions.md` - вопросы, которые нужно закрыть перед боевым запуском.

## MVP-цепочки

### Цепочка КП

```text
Telegram / веб-кабинет
-> Агент замеров
-> Агент КП
-> человек правит текстовый расчет
-> кнопка "Ок"
-> генерация КП-картинки
-> отправка в Telegram
-> сохранение в папку клиента
-> запись ссылки в Drive-индекс и реестр документов
```

### Цепочка договора

```text
запрос руководителя / менеджера
-> Агент договоров ищет последнее подтвержденное КП
-> получает паспортные данные или берет данные клиента из базы
-> формирует договор по шаблону
-> сохраняет договор
-> Агент монтажей добавляет монтаж в Google Таблицу
-> Агент документов ставит срок удаления КП через 7 дней после заключения договора
```

### Цепочка звонка

```text
Билайн АТС / другая телефония
-> Телефония агент
-> Агент транскрипции
-> Агент анализа звонков
-> Агент контроля скриптов
-> amoCRM агент обновляет карточку и задачу
-> Агент руководителя показывает риски
```

## Главный принцип

AI не должен заменять руководителя, менеджера или юриста в рискованных местах. Он снимает рутину, структурирует данные, готовит черновики и ставит задачи. Деньги, договоры, скидки, финальные статусы сделок и отправка документов клиенту проходят через подтверждение человека.

## Боевые имена агентов

Эти имена используются в коде, логах, очередях задач и системных промтах:

- `se.dispatcher` - диспетчер событий.
- `se.amocrm_operator` - оператор amoCRM.
- `se.telephony_collector` - сборщик звонков и записей.
- `se.transcriber` - транскрибатор аудио.
- `se.call_sensei` - аналитик звонков.
- `se.script_coach` - тренер продаж и контроля скриптов.
- `se.measurement_engineer` - агент замеров.
- `se.proposal_master` - мастер коммерческих предложений.
- `se.contract_master` - мастер договоров.
- `se.document_keeper` - хранитель документов.
- `se.montage_planner` - планировщик монтажей.
- `se.owner_pilot` - агент руководителя.
- `se.payroll_keeper` - агент табеля и выплат.
- `se.render_worker` - технический воркер генерации PNG/DOCX/PDF.

## Подключенные skills

- `septik-proposal-generation` - расчет и PNG коммерческого предложения для `se.proposal_master`.
- `septik-contract-generation` - договоры DOCX/PDF, монтажная строка и cleanup КП для `se.contract_master`.

## API-first принцип

Система не строится через n8n и ручные ноды. Все интеграции работают через наш backend API:

```text
webhook/API event -> очередь задач -> агент -> внешний API/renderer -> Google Drive/Sheets -> веб-кабинет/Telegram/amoCRM
```

Агент не "кликает руками" в сервисах. Он получает JSON, возвращает JSON, а backend вызывает amoCRM API, Google API, Telegram Bot API, API телефонии, OpenAI/Yandex SpeechKit и технический renderer.
